# Privacy Policy for Jira Ticket Creator Chrome Extension

**Last updated: December 2024**

## Overview

This privacy policy describes how the Jira Ticket Creator Chrome Extension ("the Extension") handles your data. We are committed to protecting your privacy and being transparent about our data practices.

## Data Collection and Usage

### What Data We Collect

The Extension collects and processes the following types of data:

1. **Selected Text**: Text that you manually select on web pages
2. **Configuration Data**: Your OpenAI API key, Jira credentials, and project settings
3. **Usage Data**: Basic extension functionality data (no personal information)

### How We Use Your Data

1. **Selected Text**: 
   - Sent to OpenAI's ChatGPT API for analysis
   - Used to generate Jira ticket content
   - Not stored permanently by the Extension

2. **Configuration Data**:
   - Stored locally in Chrome's secure storage
   - Used to authenticate with OpenAI and Jira APIs
   - Not transmitted to any third parties except the respective API services

3. **Usage Data**:
   - Used to provide extension functionality
   - No personal information is collected or transmitted

## Data Storage

### Local Storage
- All configuration data (API keys, credentials) is stored locally in Chrome's sync storage
- Selected text is temporarily stored in Chrome's local storage during processing
- No data is stored on external servers

### Third-Party Services
The Extension integrates with the following third-party services:

1. **OpenAI API**:
   - Purpose: Analyze selected text and generate ticket content
   - Data sent: Selected text only
   - Data retention: Subject to OpenAI's privacy policy
   - Privacy policy: https://openai.com/privacy/

2. **Jira API**:
   - Purpose: Create tickets in your Jira instance
   - Data sent: Generated ticket content and metadata
   - Data retention: Subject to Atlassian's privacy policy
   - Privacy policy: https://www.atlassian.com/legal/privacy-policy

## Data Security

- All API communications use HTTPS encryption
- API keys are stored securely in Chrome's encrypted storage
- No data is transmitted to servers other than OpenAI and Jira APIs
- The Extension does not collect or store personal information

## Your Rights

You have the right to:
- Access your stored configuration data
- Delete your configuration data (remove the extension)
- Control what text you select and analyze
- Revoke API access by deleting API tokens

## Data Sharing

The Extension does not share your data with any third parties except:
- OpenAI (for text analysis)
- Atlassian/Jira (for ticket creation)
- These integrations are necessary for the Extension's core functionality

## Children's Privacy

The Extension is not intended for use by children under 13. We do not knowingly collect personal information from children under 13.
